Original source mesh, shader text and material parameters are preserved here. Unity adaptation is an isolated Phase2A study: normalize blade height, derive lower-detail triangle meshes from the same silhouette, translate world-wind and color-ramp behavior into URP, and omit character interaction for this landscape game. Any production adoption must retain this credit in the in-game asset credits and include the license. The Godot shader is stored as text so Unity does not try to compile it.

No generated image or paid asset. The supplied native Godot demo has not been run; these are inspected source inputs, not an accepted visual result.
