# Study41 — layered sward trial, rejected as the main direction

Patterns TN-02/09/10/12. The [visual gate](../../../PHASE_2A_GOAL.md) remains open. This test changes grass construction rather than adding more scattered plant instances. No image generation, paid resources, analytical geography or annual-state changes.

Eight displaced terrain layers created a continuous low grass surface using the existing JulioVII meadow texture. Coverage uses existing land, road and river masks. A bounded region received 384 temporary renderers and 1,622,400 submitted mesh vertices across all layers; 26,201 existing groundcover transforms were removed from that region for the trial. These counts are construction diagnostics, not browser performance measurements. The layers reuse ground meshes, have no separate shadow-casting pass and were not optimized or integrated with annual treatment lifecycle.

The first control uses 0.65m nominal height and source grass coverage. [Normal](study41-shell-normal.png) and [close](study41-shell-close.png) show less isolated plant noise, but conspicuous mask boundaries, a smooth distant surface and fine grain close up. The continuity control includes the already illustrated sealed-context surface, uses 1.15m nominal height, and tests the existing painted terrain at 12m rather than 40m texture scale. [Normal](study41-continuity-normal.png) and [close](study41-continuity-close.png) improve continuity and remove oversized painted blades, but look like a fuzzy carpet. This does not provide the reference's rich, grounded environmental forms. Do not promote this shader or keep tuning its density/color as the primary approach.

[Before](study41-before.png) is the current study39 rendering at the same opening camera. All captures are 1280×720 Unity camera renders; none are Chrome acceptance evidence. The game controller was disabled after setting the controlled camera; there was no gameplay verification.
