# Study61 — narrower bank profile, rejected

Patterns TN-02/09/10/12; see the [design reference](../../../DESIGN_REFERENCE.md). This runtime-only trial narrowed the existing two-metre channel cut, widened its ribbon and rebuilt the retained river meadow against the changed ground. It changed 8,823 ground vertices and their normals. Annual state remained unchanged.

[Control close](study61-control-close.png) → [profile close](study61-profile-close.png); [control normal](study61-control-normal.png) → [profile normal](study61-profile-normal.png). These are actual Editor camera captures. The whole-scene benefit was insufficient; the profile was rejected and Play-mode changes discarded. Production river geometry remains unchanged. No Chrome export or performance claim.

The exact trial, camera setup and receipt are preserved alongside this note. This closes the current-profile experiment; repeat parameter tuning is not evidence of a new visual direction.
