The trial changes7802 terrain vertices in a bounded view, leaves analytical Height and annual state unchanged, and alternates shelf/steep profiles around the mapped route. It does not infer surveyed banks or sediment transport. The route projection uses raw segments in this exploratory replay; production would need the same rounded-route treatment as the terrain and plants. Plant roots were not fully re-grounded to the altered profile, another reason not to adopt it.

[Simple Lit control](study38-native-grass-lit.png), using the same artist texture, also lacks readable planted mass. These are failed integration trials, not proof the original pack is poor.
