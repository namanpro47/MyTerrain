# Phase 2A human evaluation

External usability and reference-quality validation are **pending**. No recruited first-time participants completed the structured task in this session. The user briefly explored the same local Chrome tab while automation was running, then explicitly yielded control; that exploration is not counted as an uncoached usability study.

Engineering checks and internal visual comparisons are separate evidence. No claim of commercial-game equivalence, player preference, physical trackpad testing, or three-person success rates is made.

For a later user-arranged session, give three first-time players the same task without coaching: choose a treatment, inspect a compatible site, explain cost and productive change, place, undo, recover from a blocked action, and find sources/assumptions. Record first valid action time, hesitation, errors and recovery. Target 2/3 valid placements within 60 seconds, all able to undo, and 2/3 able to explain both the preview and hypothetical nature of the proposals. Compare matched reference and Terra frames with a neutral question about unfinished areas. Findings reopen affected gaps.
