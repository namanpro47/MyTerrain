# Actual browser interaction capture

Chrome public build at 1280×720. `interaction.gif` combines actual default/hover captures, ten placement frames (timestamps retained; 279 ms between first and last), and placed/undo/blocked captures. Playback adds dwell to the still states and uses 30 ms per placement frame; this is a condensed sequence, not a continuous real-time video. No rendered pixels were invented. Source checkpoint and URL are in `../identity.json`.
